3. SEGURANÇA
═══════════════════════════════════════════════════════════════════════════════

✅ SessionToken (Anti-Rateio)
   - Cada login gera um novo token único de 32 bytes
   - Token anterior é invalidado automaticamente
   - Requisições com token inválido são rejeitadas (403 Forbidden)
   - Testado: Token falso retorna erro de acesso bloqueado

✅ HMAC-SHA256 (Anti-Fraude de Horas)
   - Implementado na rota /registrar-tempo
   - Heartbeat criptográfico a cada 60 segundos
   - Chave: DIRETRIZ_SEGURANCA_MAXIMA_CONCURSOS_2026
   - Assinatura validada antes de incrementar minutos_estudados

✅ Banco de Dados
   - PostgreSQL com encoding UTF-8
   - Tabelas criadas automaticamente via SQLAlchemy
   - Relação email única para usuários
   - Histórico de questões rastreável

8. PRÓXIMOS PASSOS
═══════════════════════════════════════════════════════════════════════════════

Para usar o sistema:

1. Acesse http://localhost:8000 no navegador
2. Clique em "Cadastre-se" ou "Não tem conta? Cadastre-se aqui"
3. Preencha email, senha e nome
4. Faça login com suas credenciais
5. Selecione:
   - Concurso: PMDF (Cebraspe) ou STT (Exército)
   - Matéria: Português, Direito Penal, Logística/Adm
   - Dificuldade: Fácil, Médio, Difícil
6. Clique "Gerar Questão Inédita"
7. Responda a questão
8. Veja o feedback e estatísticas
9. Estude com segurança:
   - Sessão única por dispositivo (anti-rateio)
   - Horas estudadas rastreadas com HMAC-SHA256
