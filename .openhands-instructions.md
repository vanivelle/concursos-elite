## Tratamento de Erros

### Se conexão com Supabase falhar:
```python
try:
    # tentar inserir
except Exception as e:
    log(f"❌ Erro Supabase: {e}")
    # Tentar novamente em 60 segundos
    sleep(60)
    retry()
```

### Se site não responde:
```python
# Tentar 3 vezes com exponential backoff
retries = 0
while retries < 3:
    try:
        resultado = crawler.arun(url)
        break
    except:
        retries += 1
        sleep(2 ** retries)
```

## Se Algo Deu Errado

1. Cheque os logs: `docker logs openhands-concurso`
2. Verifique conectividade: `curl http://postgres:5432` (não vai funcionar, mas tenta)
3. Teste Supabase: `SELECT * FROM questoes_banco LIMIT 1;`
4. Se falha persistir: aguarde ou escalpe ao admin
