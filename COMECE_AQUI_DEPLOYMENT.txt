AÇÃO 1️⃣  - Criar Supabase Database (5 MIN)
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Abra: https://supabase.com                                           │
│ 2. Clique: "Sign up with GitHub"                                        │
│ 3. Autorize vanivelle                                                   │
│ 4. "Create new project"                                                 │
│    - Name: concurso-elite                                               │
│    - Region: Brazil (São Paulo)                                         │
│    - Password: salve bem!                                               │
│ 5. Espere criar (2-3 min)                                               │
│ 6. Settings → Database → Connection String                              │
│    Copie a URL que começa com: postgresql://postgres:...@db...         │
└─────────────────────────────────────────────────────────────────────────┘

AÇÃO 2️⃣  - Fazer Backup & Restaurar (3 MIN)
┌─────────────────────────────────────────────────────────────────────────┐
│ Terminal 1: Exportar dados locais                                       │
│ $ pg_dump -U admin -h localhost -d admin > backup.sql                   │
│                                                                         │
│ Terminal 2: Restaurar em Supabase                                       │
│ $ psql "postgresql://postgres:SENHA@db.xxxx.supabase.co:5432/..." < backup.sql
│                                                                         │
│ Verificar:                                                              │
│ $ psql "postgresql://postgres:..." -c "SELECT COUNT(*) FROM questoes_banco;"
│ Esperado: 377                                                           │
└─────────────────────────────────────────────────────────────────────────┘

AÇÃO 3️⃣  - Deploy Backend em Railway (5 MIN)
┌─────────────────────────────────────────────────────────────────────────┐
│ 1. Abra: https://railway.app                                            │
│ 2. Clique: "Sign up with GitHub"                                        │
│ 3. Autorize vanivelle                                                   │
│ 4. "New Project" → "Deploy from GitHub repo"                            │
│ 5. Selecione: vanivelle/concursos-elite                                 │
│ 6. Clique: "Deploy"                                                     │
│ 7. Aguarde: Railway detecta Dockerfile e faz build                      │
│ 8. Vá em: Project Settings → Variables                                  │
│    Adicione:                                                            │
│    DATABASE_URL = <SUPABASE_CONNECTION_STRING>                          │
│    ENVIRONMENT = production                                             │
│ 9. Clique: "Deploy" (vai fazer rebuild)                                │
│ 10. Copie a URL gerada (algo como: concurso-elite-backend.railway.app) │
└─────────────────────────────────────────────────────────────────────────┘
