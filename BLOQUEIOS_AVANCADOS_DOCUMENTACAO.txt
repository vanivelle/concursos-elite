                    📍 DETECÇÃO IPv6
═════════════════════════════════════════════════════════════════════════════

O QUE É:
  IPv6 é a versão 6 do protocolo IP (nova versão)
  IPv4 é a versão 4 (atual, 4 octetos: xxx.xxx.xxx.xxx)
  IPv6 usa 8 grupos de 4 dígitos hexadecimais (2001:0db8:85a3:...)

POR QUE BLOQUEAR:
  • IPv6 é difícil de rastrear com ferramentas tradicionais
  • IPs IPv6 são menos documentados em blacklists
  • Pode ser usado para bypass de geolocalização
  • Permite maior anonimidade

COMO DETECTA:
  • Tenta fazer socket.inet_pton(socket.AF_INET6, ip)
  • Se não der erro, é IPv6
  • Verifica presença de ":" no IP (marca de IPv6)

EXEMPLOS BLOQUEADOS:
  ❌ 2001:0db8:85a3:0000:0000:8a2e:0370:7334
  ❌ fe80::1
  ❌ ::1 (localhost IPv6)
  ✅ 203.45.123.200 (IPv4 - aceito)

TESTE:
  curl -I https://open-notebook-8x8twkj23.vercel.app
  # Verifica qual IP você está usando

                    🔐 FLUXO DE BLOQUEIO NO LOGIN
═════════════════════════════════════════════════════════════════════════════

Quando usuário faz POST /login-enterprise:

1. Sistema obtém IP, User-Agent, Hostname
   └─ Dados brutos do cliente

2. Chama DetectorSegurancaAvancada.verificacao_completa()
   ├─ Verifica IPv6 ❌
   ├─ Verifica VPN/Tor ❌
   ├─ Verifica VM ❌
   └─ Verifica GPU Cloud ❌

3. Se QUALQUER bloqueio detectado:
   ├─ Retorna HTTP 403 Forbidden
   ├─ Mensagem: "Acesso negado por segurança. Motivo: [razões]"
   ├─ Registra tentativa na tabela LoginAuditadoModel
   └─ Escreve log crítico com detalhes

4. Se NENHUM bloqueio:
   ├─ Continua com verificações normais
   ├─ Verifica MAC address ✅
   ├─ Verifica movimento geográfico ✅
   └─ Se tudo OK → Login permitido ✅

EXEMPLO DE RESPOSTA BLOQUEADO:

  Content-Type: application/json
  
  {
    "detail": "Acesso negado por segurança. Motivo: IPv6, GPU Cloud. Contate administrador."
  }

  HTTP/1.1 200 OK
  Content-Type: application/json
  
  {

                    ⚠️ FALSOS POSITIVOS & SOLUÇÕES
═════════════════════════════════════════════════════════════════════════════

Situação: Usuário legítimo bloqueado
├─ IPv6 genuíno (empresa usa IPv6 puro)
│  └─ Solução: Solicitar suporte para whitelist IPv6
│
├─ Está em universidade/empresa com IP corporativo que parece VPN
│  └─ Solução: Verificar hostname real (pode ser falso positivo)
│  └─ Admin pode whitelisting de IP/empresa
│
├─ Usa proxy corporativo (legítimo)
│  └─ Solução: Solicitar whitelist do IP corporativo
│
└─ Está em máquina virtual de trabalho (autorizada)
   └─ Solução: Solicitar exceção temporária
   └─ Usar dispositivo real para login normal

POLÍTICA DE DESBLOQUEIO:
  1. Usuário preenche formulário de appeals
  2. Administrador verifica contexto
  3. Se legítimo, libera mediante:
     └─ Whitelist de IP
     └─ Whitelist de MAC
     └─ Exceção temporária (24h)
     └─ Aumento de segurança pós-verificação
