🔐 SEGURANÇA
════════════

✅ Autenticação
   └─ JWT (JSON Web Tokens)
   └─ HS256 algorithm
   └─ 8 horas de expiração
   └─ Token refresh automático
   └─ Implementado em: main_secured.py + main_enterprise.py

✅ Criptografia de Senhas
   └─ BCRYPT com 12 rounds (máxima segurança)
   └─ Irreversível (não pode descriptografar)
   └─ Seguro contra brute force (100+ anos para quebrar)
   └─ Validação: 12+ chars, maiúscula, número
   └─ Implementado em: main_secured.py + main_enterprise.py

✅ Comunicação
   └─ HTTPS/TLS 1.3 obrigatório
   └─ Certificados automáticos (Let's Encrypt)
   └─ Headers de segurança:
      ├─ HSTS (max-age=31536000)
      ├─ X-Content-Type-Options: nosniff
      ├─ X-Frame-Options: DENY
      └─ X-XSS-Protection: 1; mode=block
   └─ Implementado em: SecurityHeaderMiddleware

✅ Rate Limiting
   └─ 60 requisições/minuto por IP
   └─ 5 tentativas de login = bloqueio 15 min
   └─ Proteção contra DDoS e brute force
   └─ Implementado em: RateLimiter class

✅ SQL Injection Prevention
   └─ SQLAlchemy ORM (sem concatenação de strings)
   └─ Pydantic com tipos fortes
   └─ Queries parametrizadas
   └─ Validação em camadas

✅ MAC Address Tracking
   └─ Registro do MAC no primeiro login
   └─ Verificação de MAC em todo login
   └─ Bloqueio automático se MAC diferente
   └─ Use case: CLTs/Motoboys (1 dispositivo por pessoa)
   └─ Implementado em: GeolocalizacaoManager class
   └─ Dados armazenados em: LoginAuditadoModel

✅ Geolocalização com Detecção de Movimento Impossível
   └─ IP → Cidade usando GeoIP2 (MaxMind em prod)
   └─ 10 cidades brasileiras mapeadas (Brasília, SP, Rio, Salvador, etc)
   └─ Detecção: Se viagem > 1000 km/h (velocidade de avião)
   └─ Bloqueio automático + alert de segurança
   └─ Exemplo: SP → Brasília em 5 min = BLOQUEADO
   └─ Implementado em: GeolocalizacaoManager class + Haversine formula
   └─ Logs de todos os movimentos
