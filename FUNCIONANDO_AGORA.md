## 🟢 PADRÃO MANÉ (Em Cada Questão)

```
Exemplo: RLM - Negação de Condicional

Questão: Qual é a negação de "Se P então Q"?

🔴 PEGADINHA BANCA
   └─ Muitos candidatos confundem com "Se não-P então não-Q"
   └─ Resultado: Erram a questão

🟢 NÚCLEO DE ACERTO
   └─ A negação de (P→Q) é SEMPRE (P ∧ ¬Q)
   └─ Regra MANÉ: Mantém P, nega Q, conecta com E
   └─ Resultado: Acertam com certeza
```

Cada questão de RLM/Matemática segue este padrão! ✅
