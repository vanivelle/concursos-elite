FLUXO DE LOGIN:

1. Usuário acessa POST /login-enterprise
   └─ Envia email, senha, MAC address

2. Sistema obtém dados do cliente:
   ├─ IP do cliente
   ├─ User-Agent do navegador
   ├─ Hostname (reverse DNS)
   └─ Headers adicionais

3. Executa bloqueios avançados (PRIMEIRA COISA):
   ├─ DetectorSegurancaAvancada.verificacao_completa()
   ├─ Testa IPv6? ❌
   ├─ Testa VPN/Tor? ❌
   ├─ Testa VM? ❌
   └─ Testa GPU Cloud? ❌

4. Se QUALQUER bloqueio detectado:
   ├─ HTTP 403 Forbidden
   ├─ Mensagem clara: "Motivo: [razões]"
   ├─ Registra em auditoria
   └─ Escreve log crítico
   └─ ❌ LOGIN RECUSADO

5. Se NENHUM bloqueio:
   ├─ Continua com outras verificações
   ├─ Verifica MAC address
   ├─ Verifica movimento geográfico
   ├─ Verifica credenciais
   ├─ Se tudo OK → JWT token
   └─ ✅ LOGIN PERMITIDO

                        📋 GUIA RÁPIDO DE VERIFICAÇÃO
═════════════════════════════════════════════════════════════════════════════

VERIFICAR SE VOCÊ SERÁ BLOQUEADO:

1. Qual é seu IP?
   └─ Acesse: https://open-notebook-8x8twkj23.vercel.app/security/teste-bloqueios
   └─ Anote: seu_ip, versao_ip, hostname

2. É IPv6?
   └─ Se versao_ip = "IPv6" → ❌ BLOQUEADO
   └─ Se versao_ip = "IPv4" → ✅ OK

3. Está usando VPN?
   └─ Abra: https://open-notebook-8x8twkj23.vercel.app/security/bloqueios-status
   └─ Se vpn_tor = "VPN detectada" → ❌ BLOQUEADO
   └─ Se vpn_tor = "IP verificado" → ✅ OK

4. Está em máquina virtual?
   └─ Verifique hostname ou User-Agent
   └─ Se contém "virtualbox", "vmware", etc → ❌ BLOQUEADO
   └─ Se é dispositivo real → ✅ OK

5. Está em cloud com GPU?
   └─ Se hostname contém "amazonaws", "azure", "colab", etc → ❌ BLOQUEADO
   └─ Se é ISP normal → ✅ OK

RESULTADO:
   Se TODOS acima forem ✅ → Você será aceito no login
   Se QUALQUER ❌ → Você será bloqueado com mensagem clara
