═════════════════════════════════════════════════════════════════════════════
                        📞 SUPORTE & TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

❓ Frontend carrega mas não mostra questões
└─ Verificar: Backend está online?
└─ Verificar: API URL está correta em frontend/index.html?
└─ Solução: F12 → Network → procurar erro na requisição

❓ Erro 401 no login
└─ Motivo: Token expirado ou inválido
└─ Solução: Fazer logout e login novamente

❓ Erro 403 MAC diferente
└─ Motivo: MAC address registrado não bate
└─ Solução: Entre em contato (necessário desbloqueio manual)

❓ Erro 403 movimento impossível
└─ Motivo: Geolocalização detectou viagem impossível
└─ Solução: Esperar 15+ minutos ou mudar IP

❓ Database lento
└─ Solução: Verificar índices - executar:
└─ CREATE INDEX idx_concurso ON questoes_banco(concurso);
└─ CREATE INDEX idx_materia ON questoes_banco(materia);

❓ Quero testar tudo localmente
└─ Comando: docker-compose up (vê docker-compose.yml)
└─ Frontend: npm install && npm start
└─ Backend: python -m uvicorn backend/main_enterprise:app --reload
